### Network Security Projects For Phishing Data

### Phishing Website Detection using End-to-End Machine Learning Pipeline

### Developed and deployed an end-to-end ML system to classify websites as secure or malicious with ~98.9% accuracy, based on extracted network and URL-based features.

### Designed ETL, model training, and evaluation pipelines with integrated tracking using MLflow and DagsHub, and data storage in MongoDB Atlas.

### Containerized and deployed the application using Docker and hosted it on Render, enabling public API access for both model training and prediction through Render service links.

### Implemented retraining capability via FastAPI routes — allowing easy ingestion of fresh data (CSV upload), retraining, and automated tracking of updated models and performance metrics in MLflow/DagsHub.

### Enabled model versioning and comparison to evaluate newly trained models against previous versions for continuous performance monitoring.
